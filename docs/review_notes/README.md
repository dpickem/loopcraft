# Review notes

Milestone review reports and their responses. Files are named:

```
<date>_milestone_<M>_review_<NN>_<report|response>.md
```

The `review_<NN>` token pairs a report with its response (a report and its response share
the same number and differ only by the `report`/`response` role). The date prefix is when
that file was written, so a response may carry a later date than the report it answers.
